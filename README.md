# Catlink Smart Home — Portfolio Concept

An independent portfolio website exploring a clearer, more polished way to present Catlink's smart cat-care products.

## [View the live website](https://rickybosire.github.io/catlink-smart-home-concept/)

The site includes:

- A responsive homepage
- A complete product catalogue
- Individual product pages with image galleries
- A simple guide for choosing a litter box
- An interactive product finder
- A customer reviews page

## About the project

The visual direction takes inspiration from Apple's spacious layouts and product storytelling, while keeping its own structure and identity. The experience is designed to work across phones, tablets, and desktop screens, with keyboard navigation and reduced-motion support included.

Built with React, Vite, Framer Motion, and CSS.

## Run it locally

```bash
npm install
npm run dev
```
